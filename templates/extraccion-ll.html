Extracción Líquido–Líquido (L–L)

Generador de diagrama a partir de datos experimentales

Esta herramienta te permite obtener la gráfica del proceso de extracción líquido–líquido a partir de tus datos de laboratorio. Solo necesitas ingresar los porcentajes de cada componente en:

  • fase acuosa
  • fase orgánica

El sistema realiza los cálculos automáticamente y genera el diagrama listo para utilizar en reportes, tareas o tesis, sin necesidad de saber programación.

Base teórica breve

En la extracción líquido–líquido se ponen en contacto dos líquidos inmiscibles o parcialmente miscibles. Un soluto se reparte entre ambas fases hasta alcanzar el equilibrio.

Normalmente se manejan tres componentes:

  • A — Portador
  • B — Solvente extractor
  • C — Soluto

Las composiciones se expresan en porcentaje en masa y deben cumplir en cada punto experimental:

A + B + C = 100 %

Guía rápida de uso

  1. Escribe el número de conjuntos experimentales
  2. Haz clic en Aceptar
  3. Ingresa los porcentajes de A, B y C en cada fila
  4. Verifica que A + B + C = 100 %
  5. Presiona Generar diagrama
  6. Observa la gráfica generada
