Extracción sólido–líquido

Generador de gráfica a partir de datos experimentales

Este programa permite obtener la gráfica del proceso de extracción sólido–líquido a partir de tus datos experimentales. Solo necesitas ingresar los valores de:

  • A = Kg de aceite / Kg de disolución
  • B = Kg de disolución / Kg de semilla seca

El sistema realiza los cálculos automáticamente y genera una gráfica lista para usar en reportes, prácticas de laboratorio, tareas o tesis. No necesitas conocimientos de programación.

Base teórica breve

La extracción sólido–líquido consiste en poner en contacto un sólido que contiene un soluto (por ejemplo, semilla con aceite) con un solvente extractor. El solvente disuelve el aceite y luego se separa el sólido agotado del líquido con aceite disuelto.

Las razones introducidas representan:

  • A: concentración de aceite respecto a la disolución total
  • B: cantidad de disolución por cantidad de semilla seca

Cómo usar la herramienta

  1. Escribe cuántos conjuntos de datos experimentales tienes
  2. Haz clic en Aceptar
  3. Ingresa los valores de A y B que obtuviste en laboratorio
  4. Presiona Generar diagrama
  5. La gráfica aparecerá en la parte inferior
